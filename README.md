# Python-Exercise-5-


# What it solves & does:
This program solves the manual effort of calculating math tables by instantly generating multiplication factors. It takes a user-input number and outputs its complete table from 1 to 12.

# How to run & Tools used:
Run it on any standard Python compiler or IDE by executing the script and typing your chosen number. Built entirely using core Python, leveraging the input() function, data type conversion, and a for loop.
